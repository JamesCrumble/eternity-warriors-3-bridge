# Eternity Warriors 3 Bridge v0.1

Первый публичный релиз: **Eternity Warriors 3 (Glu, v4.1.0) на Android arm64** без оригинальных серверов.

Игра 32-битная (`armeabi-v7a`, Unity 4.6, Mono) и в одиночку на 64-битном телефоне не запускается. Приложение
исполняет её в qemu-user, а OpenGL ES-вызовы отдаёт на GPU телефона. Серверы Glu давно закрыты, поэтому внутри
приложения работает локальный сервер на Python (CDN, Gluon, логика боёв, лута, экипировки, ковки, гача, заданий).

## Что в релизе

| Файл | Что это |
|---|---|
| `Eternity-Warriors-3-Bridge-0.1.apk` | приложение (пакет `com.jamescrumble.ew3`), подписано release-ключом |
| `INSTALL.txt` | пошаговая установка |
| `Eternity-Warriors-3-Bridge-0.1-src.zip` | исходники, из которых собран APK |
| `qemu-patches.zip` | патчи и скрипт сборки qemu (`libqemu.so`, QEMU по GPL-2.0) |
| `SHA256SUMS` | контрольные суммы |

**Файлов игры в релизе нет.** Нужны ваши собственные: оригинальный APK Eternity Warriors 3 v4.1.0 и её данные
(cache-zip или `main.4100.com.glu.ewarriors3.obb`). Кладутся в `/sdcard/BridgeGames/com.jamescrumble.ew3/`
(подробности в `INSTALL.txt`).

## Как установить (коротко)

1. Поставить APK, открыть приложение и дать доступ ко всем файлам.
2. Положить в папку `/sdcard/BridgeGames/com.jamescrumble.ew3/` оригинальный APK игры и cache-zip (или `.obb`).
3. Нажать «Играть». Первый запуск дольше: распаковка и старт сервера занимают до минуты.

## Проверено

- OnePlus CPH2723 (Snapdragon 8 Elite, Adreno 830), Android 16: загрузка, вход в уровень, бой, около 60 кадров/с.
- Сервер на телефоне: выдача `serverpost`, `DynamicContentInfo`, бандлов, Gluon-подключение клиента.

## Известные ограничения

- Проверено на одном телефоне. На других устройствах результат может отличаться.
- Управление только сенсорное (геймпад не поддержан).
- Онлайн-режимы (PvP, рейды через Photon), покупки, реклама и соцсети отключены: серверов для них нет.
- Остальные уровни кампании (Китай, Готика, часть Греции) восстанавливаются из iOS-сборки v0.1.0 (`.ipa` кладётся
  в ту же папку). **Эта часть на телефоне ещё не проверялась**: без `.ipa` доступен базовый контент.
- Сохранения лежат на встроенном сервере в личной папке приложения и пропадают при его удалении.
- Включать «Профилирование в логе» в настройках не нужно: это отладочный режим, он может подвесить игру
  (чёрный экран, 0 FPS).
- Версия для Windows в этот релиз не входит.
