Eternity Warriors 3 Bridge - установка
======================================

Eternity Warriors 3 (Glu, v4.1.0, только 32-бит armeabi-v7a) на 64-битном телефоне: игра исполняется в qemu-user,
её OpenGL ES идёт на GPU телефона, а серверы Glu (давно закрыты) заменяет локальный сервер на Python внутри приложения.
Проверено на OnePlus CPH2723 (Snapdragon 8 Elite, Android 16).

Файлы игры в комплект не входят: нужны ваши собственные файлы версии 4.1.0.

Требования: Android 8+ (arm64), около 1 ГБ свободного места, интернет не нужен.

1. Установить Eternity-Warriors-3-Bridge-<версия>.apk (пакет com.jamescrumble.ew3). Обновление поверх v0.1 ставится
   как есть (тот же ключ подписи), данные сохраняются.

2. Открыть приложение. Оно само попросит: доступ ко всем файлам и разрешение на уведомления (нужно, чтобы сервер
   работал в фоне и показывал адрес /docs). Доступ ко всем файлам создаст папку
   /sdcard/BridgeGames/com.jamescrumble.ew3/
   Положить файлы игры в неё (по adb или файловым менеджером). Подойдёт и папка
   /sdcard/Android/data/com.jamescrumble.ew3/files/ : читаются обе.

       E-Warriors-3-v4-1-0.apk                 оригинальный APK игры 4.1.0
       E-Warriors-3-v4-1-0-cache.zip           данные игры (внутри main.4100.com.glu.ewarriors3.obb)
                                               или сам файл main.4100.com.glu.ewarriors3.obb

   Имена не важны, важны расширения: один .apk и один .zip либо .obb.

   Все уровни кампании (Греция, Китай, Готика): положите туда же расширенный пакет
       E-Warriors-3-v4-1-0-cache-extended.ew3x   (отдельный файл релиза)
   Пакет дополняет cache игры, а не заменяет его: APK и cache-zip (или .obb) остаются в папке. При следующем
   нажатии "Играть" приложение один раз распакует пакет (в ew3.log появится строка "extended pack", в server.log
   "prepared 33 recovered bundles (extended pack)"); если файл заменить, распакует заново. Удаление файла кэш не
   откатывает: чтобы вернуться к базовому набору, очистите данные приложения (сохранения тоже сотрутся).
   Вместо пакета можно положить iOS-сборку v0.1.0 (.ipa): тогда сервер конвертирует уровни сам.

   Пример:
       adb push E-Warriors-3-v4-1-0.apk /sdcard/BridgeGames/com.jamescrumble.ew3/
       adb push E-Warriors-3-v4-1-0-cache.zip /sdcard/BridgeGames/com.jamescrumble.ew3/
       adb push E-Warriors-3-v4-1-0-cache-extended.ew3x /sdcard/BridgeGames/com.jamescrumble.ew3/

3. Открыть приложение: появятся настройки, кнопка "Играть" запускает игру. Первый запуск дольше: распаковываются
   системные библиотеки и Python (~30 МБ), данные игры, расширенный пакет; сервер поднимается за несколько секунд.

Настройки:
   Лимит кадров          до 120. Реально 70-108 кадров/с в лёгких сценах, около 60-70 в тяжёлых: упор в процессор.
   Доступ из локальной сети
                         сервер слушает 0.0.0.0: с компьютера в домашней сети открывается http://<адрес телефона>:18080/docs
                         (Swagger: смотреть и менять сохранения). Логин admin, пароль виден в настройках и в уведомлении.
                         На самом телефоне /docs открывается по http://127.0.0.1:18080/docs без пароля, и когда игра свёрнута.
   Подключаться к другому серверу
                         переключатель и IPv4-адрес: игра идёт на ваш сервер (например, python server/ew3server.py
                         --host 0.0.0.0 на компьютере), встроенный не запускается.

Пока игра запущена, в шторке висит уведомление "сервер работает": оно держит сервер живым при свёрнутом приложении.

Сохранения лежат на встроенном сервере, в личной папке приложения: при удалении приложения они пропадают.

Если игра не стартует или зависла, причина пишется на экране и в файлы рядом с играми:
   ew3.log (игра и обёртка), server.log (сервер)
Профилирование в настройках включать не нужно: оно только для отладки и может подвесить игру.

Исходники и описание сборки: https://github.com/JamesCrumble/eternity-warriors-3-bridge
