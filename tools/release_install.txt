Eternity Warriors 3 Bridge - установка
======================================

Eternity Warriors 3 (Glu, v4.1.0, только 32-бит armeabi-v7a) на 64-битном телефоне: игра исполняется в qemu-user,
её OpenGL ES идёт на GPU телефона, а серверы Glu (давно закрыты) заменяет локальный сервер на Python внутри приложения.
Проверено на OnePlus CPH2723 (Snapdragon 8 Elite, Android 16): ~60 кадров/с.

Файлы игры в комплект не входят: нужны ваши собственные файлы версии 4.1.0.

Требования: Android 8+ (arm64), около 1 ГБ свободного места, интернет не нужен.

1. Установить Eternity-Warriors-3-Bridge-<версия>.apk (пакет com.jamescrumble.ew3).

2. Открыть приложение и разрешить доступ ко всем файлам (приложение предложит само): оно создаст папку
   /sdcard/BridgeGames/com.jamescrumble.ew3/
   Положить файлы игры в неё (по adb или файловым менеджером). Подойдёт и папка
   /sdcard/Android/data/com.jamescrumble.ew3/files/ : читаются обе. Без доступа приложение работает со второй.

       E-Warriors-3-v4-1-0.apk                 оригинальный APK игры 4.1.0
       E-Warriors-3-v4-1-0-cache.zip           данные игры (внутри main.4100.com.glu.ewarriors3.obb)
                                               или сам файл main.4100.com.glu.ewarriors3.obb

   Имена не важны, важны расширения: один .apk и один .zip либо .obb.
   Необязательно: iOS-сборка v0.1.0 (31263-Eternity-Warriors-3-v0-1-0.ipa, расширение .ipa) - сервер достаёт из неё
   недостающие уровни кампании. Эта часть на телефоне ещё не проверялась.

   Пример:
       adb push E-Warriors-3-v4-1-0.apk /sdcard/BridgeGames/com.jamescrumble.ew3/
       adb push E-Warriors-3-v4-1-0-cache.zip /sdcard/BridgeGames/com.jamescrumble.ew3/

3. Открыть приложение: появятся настройки (разрешение, лимит кадров, звук), кнопка "Играть" запускает игру.
   Первый запуск дольше: распаковываются системные библиотеки и Python (~30 МБ), данные игры, затем стартует сервер
   (до минуты). Дальше запуск быстрее.

Сохранения лежат на встроенном сервере, в личной папке приложения: при удалении приложения они пропадают.

Если игра не стартует или зависла, причина пишется на экране и в файлы рядом с играми:
   ew3.log (игра и обёртка), server.log (сервер)
Профилирование в настройках включать не нужно: оно только для отладки и может подвесить игру.

Исходники и описание сборки: https://github.com/JamesCrumble/eternity-warriors-3-bridge
